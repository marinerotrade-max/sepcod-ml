# Auto Multilingual SEO Translator Plugin

This repository contains the Auto Multilingual SEO Translator WordPress plugin - a comprehensive solution for automatic website translation with advanced SEO features.

## Overview

The Auto Multilingual SEO Translator plugin automatically translates WordPress website content into multiple languages using the Google Translate API. It includes advanced features like:

- **Multi-language Support**: 30+ languages supported
- **SEO Optimization**: hreflang tags, Open Graph tags, and multilingual sitemaps
- **Performance**: Advanced caching system for fast translations
- **Auto Detection**: Automatic language detection from user browser settings
- **Plugin Compatibility**: LiteSpeed Cache, Rank Math SEO, Wordfence, Elementor, and Directorist
- **User-Friendly**: Language switcher widget and shortcode

## Requirements

- WordPress 6.0+
- PHP 8.0+
- Google Translate API key

## Installation

1. Copy the `auto-multilingual-seo-translator` folder to your WordPress `wp-content/plugins/` directory
2. Activate the plugin in WordPress admin
3. Configure settings at Settings > Multilingual SEO
